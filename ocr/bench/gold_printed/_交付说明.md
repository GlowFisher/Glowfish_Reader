# 认证测试集交付说明（P0.2）

> 你提供真实史料，我负责跑识别 + 把转写文本转成 `<stem>.gt.json` + 出回归基线。
> 两套测试集各建议 **30–50 页**：本目录放**真实清晰印刷**，`../gold_handwritten/` 放**楷体手写**。

## 每套要给两样东西

1. **图片**：竖排繁体页扫描件。
   - 格式 jpg / png（PDF 先转 png 也行，我可代转）。
   - 命名：同一文档多页用 `<文档名>_p1.jpg, <文档名>_p2.jpg …`（页号连续，我按页号拼成文档级评分）；单页材料直接 `<名>.jpg`。
   - 印刷集尽量覆盖多来源：民国报纸 / 古籍 / 民国书刊 / 公文，字号大小、栏目繁简各来几页。

2. **转写文本**（每个文档/页一份，简体点校整理本即可，就像样本01/02 随附的「输出样式.docx」）。
   - 给 docx 或 txt 都行，我转成 gt.json。
   - 没有现成转写也行——我先跑「待核初稿」，你在校对界面（`proofread/`）精校定稿，我再回填成 GT。

## GT 文件格式（我来生成，你不用手写）

每张/每文档一个 `<stem>.gt.json`：
```json
{ "genre": "印刷",                          // 体裁：楷书/行楷/行书/草书/印刷
  "reading_order_rtl": "按右起阅读顺序的全文" }   // 简体、可含点校标点（评分时自动剥）
```
体裁标签会进分桶报告，便于看「楷体手写」「清晰印刷」各自达没达标。

## 给齐后我做什么

```
& "<codex python>" run_bench.py --engine paddle      # 识别→分页拼接→评分
```
→ 出 `out/回归报告.md`，对照硬门槛：**清晰印刷 F1 ≥ 0.98、楷体手写 F1 ≥ 0.92**，
据此决定 P1（印刷调参）/ P2（手写上视觉大模型）各要补多少。
