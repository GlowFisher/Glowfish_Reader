# 域名子域名与服务器接入实施指南

本文面向 Glowfish_Reader 当前的账号/会员制度：用户通过手机号注册、登录，服务器判断试用/会员/封禁状态；用户史料、设置、OCR 结果仍全部保存在本机。

你只需要一个正常购买的域名，例如 `yourdomain.com`。`www.yourdomain.com`、`license.yourdomain.com`、`dl.yourdomain.com` 都是这个域名下面的子域名，不需要再买新域名。

---

## 1. 最终上线结构

推荐结构如下：

| 地址 | 用途 | 是否必须 |
|---|---|---|
| `https://www.yourdomain.com` | 官网：介绍、下载、更新说明、联系方式 | 推荐必须 |
| `https://license.yourdomain.com` | 账号 API + 后台 `/admin` | 必须 |
| `https://dl.yourdomain.com` | 安装包和更新文件下载 | 可选，可先不用 |

第一阶段可以只做两个子域名：

```text
www.yourdomain.com      官网 + 下载文件
license.yourdomain.com  账号服务/API/后台
```

客户端下载和更新文件可以先放在官网同源：

```text
https://www.yourdomain.com/dl/glowfish_reader_setup_x.y.z.exe
https://www.yourdomain.com/update.json
```

账号服务固定使用：

```text
https://license.yourdomain.com/account/register/phone
https://license.yourdomain.com/account/login/password
https://license.yourdomain.com/account/check
https://license.yourdomain.com/admin
```

## 2. 大概需要多久

如果域名已经买好、服务器已经能登录：

| 阶段 | 预计耗时 |
|---|---:|
| DNS 子域名解析 | 10 分钟配置，生效通常 10 分钟到 2 小时 |
| 服务器基础环境 | 30-60 分钟 |
| 部署账号服务 | 30-90 分钟 |
| 配 Nginx + HTTPS | 30-60 分钟 |
| 配阿里云短信 | 半天到 2 天，主要看签名/模板审核 |
| 客户端改正式域名并打包 | 30-90 分钟 |
| 端到端验收 | 1-2 小时 |

最快：同一天能跑通测试环境。  
正式可用：通常 1-3 天，短信审核和域名备案/证书是主要变量。

如果服务器在中国内地，官网/API 对公网服务通常还涉及 ICP 备案，备案时间可能按天到周计算。香港或海外服务器通常不需要大陆 ICP 备案，但大陆访问速度和稳定性要实测。

## 3. 你需要先准备什么

### 3.1 域名

准备一个主域名，例如：

```text
yourdomain.com
```

在域名 DNS 控制台添加：

```text
主机记录      类型   记录值
@             A      服务器公网 IP
www           A      服务器公网 IP
license       A      服务器公网 IP
```

如果以后想单独做下载域：

```text
dl            A      服务器公网 IP
```

说明：

- `@` 表示裸域名 `yourdomain.com`。
- `www` 表示 `www.yourdomain.com`。
- `license` 表示 `license.yourdomain.com`。
- 都可以先指向同一台服务器，由 Nginx 按域名分流。

### 3.2 云服务器

建议最低配置：

```text
2 核 CPU / 2G 内存 / 40G 磁盘 / Ubuntu 22.04 或 24.04
```

如果是阿里云试用服务器，也可以先用来跑测试。正式运营建议：

- 固定公网 IP。
- 数据盘或定期快照。
- 安全组只开放 `22`、`80`、`443`。
- `22` 最好限制为你自己的办公 IP。

### 3.3 阿里云短信

账号制度需要短信验证码注册，所以要准备：

- 阿里云短信服务。
- 短信签名，例如 `Glowfish阅读器`。
- 短信模板，例如：`您的验证码为 ${code}，5 分钟内有效，请勿泄露给他人。`
- RAM 子账号 AccessKey，不要用主账号 AccessKey。

短信审核通过前，可以用 `SMS_PROVIDER=console` 测试，验证码会打印在服务器日志里，不真实发送。

## 4. 服务器目录规划

建议统一放在下面这些路径：

```text
/opt/glowfish/account-server/       账号服务代码
/opt/glowfish/venv/                 Python 虚拟环境
/etc/glowfish/account.env           账号服务环境变量和密钥
/var/lib/glowfish/account.db        SQLite 账号数据库
/var/backups/glowfish/              数据库备份
/var/www/glowfish/site/             官网静态文件
/var/www/glowfish/dl/               安装包下载目录
/var/www/glowfish/update.json       客户端更新清单
```

现有项目中对应代码是：

```text
license_server/serverapp.py
license_server/core.py
license_server/sms.py
license_server/sign.py
license_server/deploy/
```

## 5. 服务器基础安装

SSH 登录服务器后执行：

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip nginx certbot python3-certbot-nginx sqlite3 ufw fail2ban
```

创建目录：

```bash
sudo mkdir -p /opt/glowfish/account-server
sudo mkdir -p /opt/glowfish/venv
sudo mkdir -p /etc/glowfish
sudo mkdir -p /var/lib/glowfish
sudo mkdir -p /var/backups/glowfish
sudo mkdir -p /var/www/glowfish/site
sudo mkdir -p /var/www/glowfish/dl
```

建议创建专用用户：

```bash
sudo adduser --system --group glowfish
sudo chown -R glowfish:glowfish /opt/glowfish /var/lib/glowfish /var/backups/glowfish
```

开启防火墙：

```bash
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

阿里云控制台安全组也要放行：

```text
22/tcp   SSH
80/tcp   HTTP，用于证书申请和跳转
443/tcp  HTTPS，正式访问
```

## 6. 上传并安装账号服务

把本地 `license_server/` 上传到服务器：

```bash
/opt/glowfish/account-server/
```

服务器上创建虚拟环境并安装依赖：

```bash
cd /opt/glowfish
python3 -m venv venv
/opt/glowfish/venv/bin/pip install --upgrade pip
/opt/glowfish/venv/bin/pip install fastapi "uvicorn[standard]" pynacl requests
```

如果 `sms.py` 使用纯标准库访问阿里云短信，通常不需要额外 SDK；如果后续改用阿里云官方 SDK，再补装对应依赖。

## 7. 准备服务器签名密钥

账号服务会签发 `account_cred`，客户端只信任服务器公钥。

在本机或服务器生成密钥均可，但要注意：

- `SERVER_PRIV` 是服务器私钥，只放服务器 `/etc/glowfish/account.env`。
- `SERVER_PUB` 是公钥，要写入客户端 `glowfish_reader/proofread/licensing/keys.py`。
- 不要把私钥提交到仓库。

可以使用现有脚本：

```bash
cd /opt/glowfish/account-server
/opt/glowfish/venv/bin/python keygen.py
```

生成后：

```text
server_private.b64 -> SERVER_PRIV
server public key  -> 客户端 SERVER_PUB
```

## 8. 配置账号服务环境变量

创建：

```bash
sudo nano /etc/glowfish/account.env
```

内容示例：

```env
LICENSE_DB=/var/lib/glowfish/account.db
SERVER_PRIV=这里填服务器私钥base64
LICENSE_PUB=如果旧授权码兼容还需要则填写，否则可先放服务器公钥占位

ADMIN_USER=admin
ADMIN_PASSWORD=请换成强密码至少12位

SMS_PROVIDER=console
SMS_SEND_COOLDOWN=60
SMS_DAILY_LIMIT=5
SMS_CODE_TTL=300
LICENSE_RATE_LIMIT=60
LICENSE_RATE_WINDOW=60
```

短信上线后改为：

```env
SMS_PROVIDER=aliyun
ALIYUN_ACCESS_KEY_ID=你的RAM子账号AK
ALIYUN_ACCESS_KEY_SECRET=你的RAM子账号Secret
SMS_SIGN_NAME=短信签名
SMS_TEMPLATE_CODE=短信模板CODE
```

设置权限：

```bash
sudo chown glowfish:glowfish /etc/glowfish/account.env
sudo chmod 600 /etc/glowfish/account.env
```

## 9. 配 systemd 常驻服务

创建：

```bash
sudo nano /etc/systemd/system/glowfish-account.service
```

内容：

```ini
[Unit]
Description=Glowfish Account Server
After=network.target

[Service]
User=glowfish
Group=glowfish
WorkingDirectory=/opt/glowfish/account-server
EnvironmentFile=/etc/glowfish/account.env
ExecStart=/opt/glowfish/venv/bin/uvicorn serverapp:app --host 127.0.0.1 --port 8800
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now glowfish-account
sudo systemctl status glowfish-account
curl http://127.0.0.1:8800/health
```

期望：

```json
{"ok": true}
```

查看日志：

```bash
journalctl -u glowfish-account -f
```

## 10. 配 Nginx：官网 + 账号子域名

### 10.1 账号服务 `license.yourdomain.com`

创建：

```bash
sudo nano /etc/nginx/conf.d/glowfish-account.conf
```

内容：

```nginx
limit_req_zone $binary_remote_addr zone=glowfish_account_zone:10m rate=60r/m;

server {
    listen 80;
    server_name license.yourdomain.com;

    location / {
        limit_req zone=glowfish_account_zone burst=20 nodelay;
        proxy_pass http://127.0.0.1:8800;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 10.2 官网 `www.yourdomain.com`

创建：

```bash
sudo nano /etc/nginx/conf.d/glowfish-site.conf
```

内容：

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    root /var/www/glowfish/site;
    index index.html;

    location = /update.json {
        alias /var/www/glowfish/update.json;
        default_type application/json;
        add_header Cache-Control "no-cache";
    }

    location ^~ /dl/ {
        alias /var/www/glowfish/dl/;
        autoindex off;
    }

    location / {
        try_files $uri $uri/ =404;
    }
}
```

放一个临时官网首页：

```bash
cat <<'HTML' | sudo tee /var/www/glowfish/site/index.html
<!doctype html><html lang="zh-CN"><head><meta charset="utf-8"><title>Glowfish Reader</title></head>
<body><h1>Glowfish_Reader 史料阅读器</h1><p>官网部署成功。</p></body></html>
HTML
```

检查 Nginx：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

```text

```

```python
DEFAULT_SERVER = "https://license.glowfishreader.com"
```

```python

```

同时确认 `SERVER_PUB` 是第 7 步服务器私钥对应的公钥。

然后重新打包客户端。

### 14.4 后台

浏览器打开：

```text
https://license.yourdomain.com/admin
```

用 `ADMIN_USER` / `ADMIN_PASSWORD` 登录。

检查：

- 能看到刚注册的手机号。
- 能延长试用。
- 能续会员。
- 能封禁/解封。
- 能重置密码。

### 14.5 客户端

在阅读器里测试：

1. 打开登录页。
2. 手机号获取验证码。
3. 注册并进入主界面。

6. 后台封禁账号，客户端下次校验后不可继续使用。

## 15. 常见问题

### 15.1 我只有一个域名，可以这样做吗？

可以。`www.yourdomain.com` 和 `license.yourdomain.com` 都是同一个域名下的子域名，不需要再买域名。

### 15.2 官网和账号服务能不能放同一台服务器？

可以。Nginx 会按访问的域名分流：

```text
www.yourdomain.com      -> /var/www/glowfish/site
license.yourdomain.com  -> 127.0.0.1:8800 FastAPI
```

### 15.3 以后用户多了怎么办？

第一阶段 SQLite 足够低维护。后续如果用户量明显增长，可以迁移到 PostgreSQL，但 API 和客户端协议不需要大改。

### 15.4 服务器私钥丢了怎么办？

`SERVER_PRIV` 丢失后，旧客户端内置的 `SERVER_PUB` 将无法验证新服务器签发的账号凭据。需要发新版客户端，更新 `SERVER_PUB`。

### 15.5 短信审核没过怎么办？

先用 `SMS_PROVIDER=console` 完成内部测试；审核通过后再切换 `SMS_PROVIDER=aliyun`。

## 16. 推荐执行顺序

1. 确认正式域名，例如 `yourdomain.com`。
2. 决定服务器地域：香港/海外最快；中国内地通常需要备案。
3. 添加 DNS：`@`、`www`、`license` 指向服务器 IP。
4. 在服务器安装 Python、Nginx、Certbot。
5. 上传 `license_server` 到 `/opt/glowfish/account-server`。
6. 生成并配置 `SERVER_PRIV`，把 `SERVER_PUB` 回填客户端。
7. 配 `/etc/glowfish/account.env`。
8. 启动 `glowfish-account.service`。
9. 配 Nginx 和 HTTPS。
10. 用 `console` 短信跑通注册、登录、后台。
11. 开通阿里云短信，切换 `SMS_PROVIDER=aliyun`。
12. 修改客户端 `DEFAULT_SERVER`，重新打包。
13. 上传安装包到官网 `/dl/`。
14. 小范围内测。
15. 正式发给用户。
