# GlowFish 账号后台 · 低维护部署说明

本方案继续复用现有 `license.glowfishreader.com` 授权服务器，不新增 Supabase/Postgres。
账号、试用、订阅、封禁和使用汇总都保存在同一个 SQLite 数据库文件中。

## 数据边界

服务端只保存：

- 用户名、密码哈希、注册时间
- 试用/订阅到期时间、是否封禁
- 登录会话、最后校验时间、软件版本、设备指纹哈希摘要
- 使用汇总：登录、校验、导入、OCR、导出、错误次数、累计秒数

服务端不保存：

- 史料图片
- OCR 文本
- 笔记正文
- 文件名
- 本地路径

## 首次部署/升级

服务器 Python 环境需要安装：

```bash
pip install fastapi "uvicorn[standard]" pynacl python-multipart
```

环境变量新增：

```bash
ADMIN_USER=你的管理员账号
ADMIN_PASSWORD=至少8位的管理员密码
```

首次启动时，如果数据库里还没有管理员账号，会自动创建该管理员。

后台入口：

```text
https://license.glowfishreader.com/admin
```

## 日常运营

1. 用户在客户端注册账号，自动获得 7 天试用。
2. 用户付款后，在后台搜索用户名，进入详情页，点击“续期天数”。
3. 需要停用用户时，在详情页点击“封禁账号”。
4. 用户下次启动或使用核心功能时，会联网校验并立刻生效。

## 备份

备份线上真库 `/var/lib/glowfish/account.db`（⚠旧 `/var/lib/shupai/license.db` 是激活码时代的退役空库，备它等于没备份）。建议每天备份一次 SQLite 文件，例如：

```bash
sqlite3 /var/lib/glowfish/account.db ".backup '/var/backups/glowfish/account-$(date +%F).db'"
```

如果未来用户量明显增加，再考虑把这些表迁移到 Postgres/Supabase/Cloudflare D1。
