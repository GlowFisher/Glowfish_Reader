# Glowfish Reader 下一版本更新说明

## OCR 缓存与兼容性

- 修复运行 OCR 时出现 Z:/Y: 临时磁盘的问题。
- OCR 缓存改为 Windows 每用户隔离目录，不再创建任何临时盘符。
- 新安装用户的数据目录使用 `%APPDATA%\Glowfish Reader`。
- 升级用户继续使用原有数据目录，账号、文档、日志与 WebView 数据不会迁移或删除。
- 首次启动可安全清理由旧版本遗留、且明确指向 Glowfish 历史数据目录的盘符映射；网络盘、用户自建映射及其他软件盘符不受影响。

如果系统提供的所有无盘符缓存位置均不可写，OCR 会返回可诊断错误，不会恢复创建虚拟盘符。
