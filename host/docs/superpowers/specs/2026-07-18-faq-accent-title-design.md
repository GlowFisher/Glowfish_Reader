# FAQ 强调色标题条设计

## 目标

将官网 FAQ 的三条常显问答重新组织为适合史料研究者快速扫读的阅读卡片；保留既有蓝白视觉语言，提升问题与答案的层级区分。

## 设计方向

采用“强调色标题条”。每张卡片的标题置于低饱和蓝色题签上，题签左侧用细竖线呼应史料页的分栏标记；答案位于留白更充足的白色正文区。三张卡片保持常显，无可点击、展开或折叠行为。

## 视觉令牌

- 墨蓝：`#132a52`，用于问题文字与细分隔线。
- 题签蓝：`#e9f1ff`，用于问题标题背景。
- 链接蓝：`#3867ff`，用于题签左侧强调线。
- 纸白：`#ffffff`，用于答案阅读区。
- 雾蓝：`#f6f9ff`，用于卡片外层的轻微层次。

问题标题继续使用加粗新细明体；答案沿用当前无衬线正文，确保中英文混排、技术名词和长句的可读性。

## 布局与响应式

桌面端三张卡片维持垂直节奏，题签和答案在同一张卡片内分区，避免横向视觉跳跃。窄屏时保留题签在上、正文在下的单列阅读顺序，内边距随视口缩小。

## 验收标准

1. FAQ 仍只有三条常显问答，页面中不含 `details`、`summary` 或 `faq-toggle`。
2. 每条标题具有独立的强调色标题条，包含左侧蓝色强调线。
3. 标题使用加粗新细明体字体栈，答案保持易读行距。
4. 样式文件版本号更新，避免浏览器读取旧 CSS 缓存。
