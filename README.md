# Glowfish Reader Host

Private Windows integration repository for the desktop shell, local FastAPI app,
document/proof/export/library services, component assembly, installer, and release
website. UI, OCR, Account, and Contracts are immutable gitlink dependencies under
`components/`.

Clone with `git clone --recurse-submodules`. Never update a component by following a
branch; update one gitlink and `component-manifest.json` together in a reviewed PR.
